### 4. 요트 다이스 (진행중)

#### 🎯 구현 목표
##### 요트 다이스 ver 1 - 완료  
기본 카테고리 4개로 게임 진행
- Ones, Twos, Threes, Choice
- 4라운드
- 재굴림 없음

##### 요트 다이스 ver 2 - 완료
숫자 카테고리 전체 + 조합 카테고리 추가
- Fours, Fives, Sixes 추가
- Four of a Kind, Yacht 추가
- 9라운드로 확장
- 재굴림 없음

##### 요트 다이스 ver 3 - 예정 
조합 카테고리 추가

- Small Straight (1,2,3,4,5 또는 2,3,4,5,6)
- Large Straight (1,2,3,4,5,6)
- 선택한 주사위 다시 재굴림
- 주사위 재굴림 (제한 3번)

## 📝 학습 내용

### 문자열 계산기에서 배운 것
- TDD 방식 개발 (Red-Green-Refactor)
- 메서드 분리를 통한 단일 책임 원칙
- Early Return 패턴으로 else 제거
- Enum을 활용한 에러 메시지 관리
- 작은 단위의 의미 있는 커밋

### 자동차 경주에서 배운 것
- 일급 컬렉션 패턴 적용
- 객체에 메시지 보내기
- 레이어 구조 (Domain, View, Controller)
- 의존성 주입으로 유연한 설계
- 책임 분리와 캡슐화
- try-catch로 예외 처리

### 로또에서 배운 것
- Enum 활용한 등수 관리와 상금 계산
- 일급 컬렉션 (Lottos)으로 객체 관리
- Domain 중심 설계 (비즈니스 로직 분리)
- Generator 패턴으로 객체 생성 분리
- 상수 통합 관리 (DRY 원칙)
